## Brand colours

The  brand guidelines already provide four colour options displayed below. These colours are appropriate for titles & subtitles, and general text. Using the brand colours for these elements helps integrate data visualization with the products they are used in and ensures a unified and recognizable style. 

However, data visualisations have additional needs when it comes to colours. Colours are used as a pre-attentive attribute to differentiate nominal categories, ramps with graduated shades of a single colour are used to differentiate ordinal categories and diverging ramps with shades of two contrasting colours are used to visualise contrasting categories. None of these requirements can be met with the current selection of brand colours, so additional sets of colour palettes have been developed to meet these needs.

## Data colours

There are seven data colours in total. The primary data colour is ‘Ocean’, a slightly lighter blue shade than INSO brand primary blue. This differentiates data content from branded content and puts it more in line with the additional data colours. When more than one data category is present, additional colours should be chosen in top-to-bottom sequence from either the complementary order (left) or the analogous order (right). Any number of categories may be supplemented with the neutral Steel colour if necessary.

Using more than these 7 colours and grey is strongly discouraged. Although there are some visualisation types where a higher number of colours can still be meaningfully distinguished (most notably bar charts) (Szafir, 2018), using that many categorical colours in a single visualisation will lead to other issues such as cluttering, reducing the size of visual elements, or overcrowding of legends. In these cases, consider alternative ways of presenting the data such as small multiples or grouping categories.

## Single colour ramps

Single colour ramps are used to visualise quantitative differences in a single measure, or to indicate ordinal (i.e. ranked) categories. They can be used with continuous data if binned first.

Single colour ramps provide up to seven steps but be aware that this already at the high end of what people can meaningfully distinguish (Tseng et al., 2024). Using 5 or 6 steps as a maximum is generally better. Note that when using fewer than 7 steps in a single colour ramp, shades should not be selected sequentially. Instead, to keep reasonable difference between shades, add them to the ramp in this order: 3, 6, 5, 2, 7, 4, 1.

Finally, although colour ramps for all data colours are provided, combining some of these ramps into a single visualisation is discouraged. Specifically, avoid using the ‘sky’ or ‘rust’ ramps in the same chart as ‘ocean’ or ‘coral’ respectively.

## Divering colour ramps

Diverging colour ramps are used to visualise opposite ends of a spectrum. This can take several forms: ‘good – bad’, ’less – more’, or even ‘more x – more y’. In either case, care should be taken to construct a diverging colour ramp from two contrasting colours. The ramp shown below is an example, additional colour ramps can be created by combining two of the single colour ramps above (considering the shade selection order outlined above). When a neutral middle colour is required, use light grey from the brand colours or the neutral silver if you need more contrast with a white background. Much like the single colour ramp, although it is technically possible to create a 15-step ramp with this palette, perception accuracy drops after more than 9 steps for diverging colour ramps (Tseng et al., 2024)

# Design process
To determine an appropriate set of data colours for the visualisation standards three sets of criteria were followed, listed below in declining order of importance.

1.	Clear visual language: to help achieve a clear visual language, selected colours must provide clearly identifiable colour categories and easily distinguishable steps in colour ramps. There must be sufficient colour choices for most data visualisation needs. 
2.	Accessibility: the chosen palette must be colour-blind friendly, there must be sufficient contrast between the chosen colours, and colours must still be distinguishable when displayed in greyscale. Colours must appear well in print & digitally.
3.	Aesthetics:  if we ensure the other criteria are still met, we can consider aligning with our brand colours in the data colour selection. We can select colours that we consider pleasant and convey a professional image (while remembering that these are subjective matters).

## Starting point

Since the matters of clear visual language and colour-blind friendliness partly overlap, three existing colour palettes were identified that are developed specifically to work well with most common varieties of colour blindness. Preference was given specifically to colour palettes designed to work with categorical data as this is the type of data we presents in its visualisations most often.

An additional consideration was provided during consultation with the Lead UI/UX Designer. A palette of highly saturated colours causes issues when visualisations are presented in print. Two measures can be taken to mitigate this issue: first to decrease the saturation of colours; second to move towards more pastel colours (i.e. increased white).

## Colour palette choices
Creating a colour palette with enough colours that all sufficiently contrast with each other is an impossible task. Several existing style guides solve this issue by prescribing which combinations of colours to use when using fewer than the maximum number of colours, others simply prescribed a specific order in which to add additional colour. Both provide the added value that it increases consistency of visualisations by always using the same or similar colour combinations. To keep things simple while still providing flexibility, two options are presented in this style guide: one with colours in complementary order to maximize individual contrast, and another with colours in analogous order to provide a gradient effect that might be considered more aesthetically pleasing.

Several colour palettes were created based on the Okabe-Ito colour palette. A final decision was made for the colour palette presented in this document. The black was replaced by a neutral grey tint, as this is more in line with the lightness of the other data colours and provides a useful option for de-emphasising data series that are not the focus of a visualisation. Inspired by the Database chart colours, it replaces pink with a purple hue. This reduces the colour-blind friendliness a little bit, but in return it replaces one of the more poorly contrasting colours with a better alternative.
