# Big numbers (BANs)

A big aggregated number (BAN) is one value that delivers the key insight at a glance. It is the simplest visualisation there is.

<div class="ban"><span class="ban__label">Security incidents, March 2026</span><span class="ban__value">112</span><span class="ban__context">▲ +24% on the 12-month average</span></div>
<div class="ban"><span class="ban__label">Missions denied or delayed</span><span class="ban__value">27%</span><span class="ban__context">About 1 in every 4 planned missions</span></div>
<div class="ban"><span class="ban__label">Days without recorded clashes</span><span class="ban__value">23</span><span class="ban__context">Longest lull in two years</span></div>

| Use a big number when… | Don't use one when… |
|:--|:--|
| The message is one number or fact | The reader needs several data points to understand the message |
| You want to show an outcome rather than a relationship | The insight lies in a comparison, distribution or composition |
| You want to break up dense text | You'd need more than three or four on the same page |
| The surrounding text can provide context | |

## Rules

{: .rule }
Every big number has a label (what it is, including units and period) and a line of context.

{: .rule }
Use them sparingly. Pick only the numbers that sum up the core message. A page full of big numbers is a table with bad formatting.

{: .rule }
Put them where the narrative needs them, usually at the start of a section or in the margin.

## Making the number mean something

Readers understand a number better when it's related to something they know:

- "Equivalent to X% of Y"
- "About the same as X"
- "Roughly X times higher than last year"
- "About one X for every Y"

## Style

- Show the value in bold and large, in Black or Dark Teal, with tabular figures.
- The label and context line are regular weight and smaller.
- Use brand colours for the number and any accent. Up and down arrows may use the [data colours](../../colour/categorical/), but always together with a + or − sign.

{: .why }
Barrio, Goldstein and Hofman (2016) found that "perspective" sentences like those above make numbers in the news easier to understand and remember. See [references](../../background/references/).
