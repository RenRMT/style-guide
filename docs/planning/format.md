# Choose a format

Choose the simplest format that still makes your point.

| Your message is… | Use | Go to |
|:--|:--|:--|
| One number or fact, an outcome rather than a relationship | A **big number** (BAN), optionally with a sparkline | [Big numbers](../../big-numbers/) |
| A comparison, trend, composition, distribution or relationship between two or more variables | A **chart** | [Charts](../../charts/) |
| A pattern in which *location itself* matters | A **map** | [Maps](../../maps/) |
| Exact values the reader needs to look up | A **table** | |
| A few numbers that fit in a sentence | **Text** | |

## Before you make a map

Not all data with a location should be mapped. Ask yourself:

- Does location matter for the story, or is it just available?
- Would a bar chart of regions compare them more clearly? Usually it would.
- Is a map worth the extra effort? Good maps take much more work than good charts.

If the answer is "a chart would do", use a chart.

{: .adapt }
Swap the examples on these pages for your own domain. The decision order stays the same everywhere: number, then chart, then map, from simplest to most complex.
