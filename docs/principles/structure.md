# Structure

A visualisation has a **correct structure** when the data is represented accurately. The axes, scales, transformations, and values must be truthful and precise. The reader should be able to trust that what they see reflects the real underlying data.

## Examples of well-structured visuals
- A chart that uses an appropriate scale, correctly labelled axes, and precise encoding of values (e.g., bars starting at zero, consistent units).
- A scatter plot where data points are accurately plotted, and statistical elements (trend lines, error bars) are based on real calculations.
- A map that uses a visualisation suitable for the data that is displayed, such as using a choropleth with normalised data.
- A map where the legend, scale bar, coordinates, and symbols correctly match the data and geography.

A visualisation has structural issues when it has mathematical or factual errors. These errors misrepresent the data and make it impossible for the reader to determine the values or relationships. Problems often include missing scales, distorted axes, or graphical elements that contradict the actual numbers.

## Examples of visuals with structure issues

- A bar chart where the y axis does not start at zero, creating exaggerated and misleading differences.
- A chart with mislabelled data points, an incorrect scale, or a distorted axis.
- A map that uses inconsistent scales, mismatched legends, or an unsuitable projection.
- A map with incorrect borders, inconsistent boundaries across layers, or point locations plotted with the wrong coordinates.
