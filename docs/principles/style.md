# Style

A visualisation has a **polished style** when the design choices help the reader understand the message instead of distracting from it. Colours, typography, layout, and spacing are intentional, balanced, and pleasant to look at. Good style supports the message and encourages the viewer to engage with the visual.

## Examples of visuals with a good style

- A bar chart with contrasting category colours, consistent font choices, and clean spacing that frames the data without drawing attention away from it.
- A map where labels, lines, symbols are minimal but carefully placed.

A visualisation has style issues when the design choices are distracting or unpleasant. These problems may include clashing colours, inconsistent fonts, or overly strong background elements. Even if the data is shown correctly, poor style can make the visualisation harder to read. 

## Examples of visuals with style issues

- A map with clashing, overly saturated colours that make regions difficult or uncomfortable to distinguish.
- A map with heavy drop shadows or a busy background image that distracts from the actual geography.
- A line chart with inconsistent font sizes and styles, big gridlines, and background patterns that attract more attention than the actual data.
